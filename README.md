# Calculator 🧮

A simple and responsive calculator built using HTML, CSS, and JavaScript.

## 📌 About the Project

This is a beginner-friendly calculator project created to practice JavaScript fundamentals, DOM manipulation, functions, event handling, and basic input validation.

The calculator allows users to perform basic arithmetic operations between two numbers.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Simple and clean user interface
* Interactive calculate button

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Abhishek292005/calculator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

## 🧠 What I Learned

Through this project, I practiced:

* Creating functions in JavaScript
* Handling button click events
* Reading values from HTML input fields
* Using `querySelector()`
* Using conditional statements
* Converting input values using `Number()`
* Updating HTML using `innerText`
* Handling division by zero
* Connecting HTML, CSS, and JavaScript
